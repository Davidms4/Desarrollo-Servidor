# Ejercicios de POO — PHP
David Marimón Sarmiento

- **01_Personas**: Persona y Estudiante. Abrir `clases.php`. Clases separadas en archivos para organizar la práctica.
- **02_Futbol**: Player, Team y carga del CSV. Abrir `prueba.php`. Los contadores empiezan en cero, como en la práctica; el CSV aporta los datos personales. Cada llamada a PlayMinutes cuenta un partido. Tarjetas: 1 amarilla, 2 roja.
- **03_Namespace**: Producto dentro del namespace Tienda. Abrir `prueba_namespace.php`.
- **04_Excepciones**: validación de notas y excepción propia. Abrir `prueba.php`.
- **05_Tienda**: productos, herencia, descuentos y validación de precios. Abrir `pruebaTienda.php`.

Cada carpeta se ejecuta de forma independiente mediante un servidor PHP. GitHub muestra el código, pero no ejecuta PHP.

Paquete de repaso: Persona/Estudiante y fútbol reconstruidos a partir del enunciado y la práctica; tienda basada en los archivos aportados y corregidos. Código revisado, pendiente de ejecución en PHP.
